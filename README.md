## 项目定位

本项目是一个 **L5 门槛的任务型 Agent**，具备完整的"感知 → 规划 → 执行 → 反思 → 重规划 → 复盘 → 记忆"闭环。

**它不是**：
- ❌ 一个只会调用 LLM 的聊天机器人
- ❌ 一个黑盒输出结果的工具

**它是**：
- ✅ 会**先谋后动**：先拆解任务成 TODO 列表，再逐步执行
- ✅ 会**自我纠错**：工具失败先局部反思改参数，仍失败则推翻计划重新规划
- ✅ 会**自我评估**：任务结束后做全局复盘，判断是否真正达成目标、根因是什么
- ✅ 会**感知环境**：执行前扫描沙箱目录、系统信息、可用工具，注入上下文
- ✅ 会**记住历史**：多会话持久化，重启不丢
- ✅ 会**扩展工具**：通过 MCP 协议动态加载外部工具，无需改代码

**适用场景**：本地文件管理助手、任务自动化 POC、Agent 原理学习范本、可扩展的 Agent 脚手架。

## 核心能力

| 能力 | 模块 | 说明 |
|------|------|------|
| **环境感知** | `sensor/` | 扫描沙箱目录、系统信息、可用工具，注入规划上下文 |
| **规划** | `planner.MakePlan` | 将用户任务拆解为结构化 TODO 列表 |
| **局部反思** | `reflector/` | 单步失败时分析原因、改参数重试 |
| **动态重规划** | `planner.Replan` | 重试仍失败时推翻原计划，基于最新环境重新规划 |
| **全局复盘** | `retrospector/` | 任务结束后判断目标是否达成、根因、质量评分、改进建议 |
| **工具调用** | `tools/` + `mcpclient/` | 本地工具 + MCP 外部工具，统一路由 |
| **安全沙箱** | `tools.safePath` | 所有文件操作限制在沙箱内，路径越界直接拦截 |
| **人类确认** | `agent.Run` | 执行前需用户 `y/n` 确认（可关闭） |
| **持久记忆** | `memory/` | 多会话 JSON 持久化，自动压缩，重启恢复 |
| **多会话隔离** | `/new <id>` | 每个会话独立记忆文件 |
| **可观测日志** | 全流程 | 感知/规划/执行/反思/重规划/复盘/总结七段日志 |
